 
# IT Zone Electronics

Zero-build, multi-page catalog for refurbished business laptops.
Stack: HTML5, CSS3 (custom properties + cascade layers), vanilla ES modules, Bootstrap 5.3, Lucide.

## Run locally
Any static server, e.g.:
    npx serve .
    # or
    python3 -m http.server 5173

Then open http://localhost:5173

## Structure
See `/assets/css/main.css` for the cascade entry point and
`/assets/js/main.js` for the app bootstrap.
